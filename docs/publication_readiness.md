# Publication Readiness

## Static Public-Review Verdict

Active Skillference is conditionally ready for an initial static public-review
publication of the manuscript, generated figures, curriculum export, dashboard shell, and
source tree snapshot, provided the release language stays inside the verified evidence
boundary and the dirty worktree is intentionally committed or explicitly deferred. The
repository now has a top-level MIT `LICENSE`, a third-party notice ledger in
`THIRD_PARTY_NOTICES.md`, and an IP/license boundary page at `docs/ip_license_status.md`.
The project owner has confirmed MIT for authored code/content/generated artifacts, the
`Daniel Ari Friedman` copyright holder line, the
`ActiveInferenceInstitute/Active_Skillference` public target, and the need for a
counsel-review checklist before formal release.

This is not legal advice. It is an engineering release-readiness statement for review.
It is not ready to claim a live SkillTree deployment, DOI-backed archival publication,
learner-outcome evidence, or operational security assurance until the separately tracked
roadmap tasks are complete.

## Evidence Basis

- Manuscript claims are anchored in `data/manuscript_claim_support.yaml` and validated by `scripts/validate_claim_support.py`.
- Learner-facing numbers are generated by kernels and claim tokens, then checked by `scripts/run_kernels.py`.
- Figure captions, alt text, semantic metadata, PNG information content, manuscript declarations, and dashboard artifact links are checked by `scripts/validate_manuscript_artifacts.py`.
- Authored manuscript prose is checked for American English by `scripts/validate_american_english.py`.
- Live counts and generated roadmap surfaces (`TODO.md` plus `docs/todo/`) are checked by `scripts/validate_live_counts.py` and `scripts/validate_roadmap.py`.
- Rendered web math is checked by `scripts/ensure_web_math.py` and `scripts/validate_web_math.py`.
- License, third-party notice, citation metadata, DOI, and public-repository boundaries
  are signposted in `LICENSE`, `THIRD_PARTY_NOTICES.md`, `docs/ip_license_status.md`,
  `CITATION.cff`, `.zenodo.json`, `codemeta.json`, and `manuscript/config.yaml`.
- Renderer-facing repository and release-date metadata remain blank or omitted until a real
  published release exists, so rendered PDFs, CFF, and CodeMeta do not advertise an
  unavailable release endpoint. Probed on 2026-08-09,
  `https://github.com/ActiveInferenceInstitute/Active_Skillference` exists and is public but
  holds zero refs, so the target is reachable and still unpublished.

## Release-Allowed Claims

- The curriculum graph, manuscript variables, claim registry, SkillTree JSON export, figures, and dashboard artifacts regenerate from repository sources.
- The manuscript distinguishes computed, descriptive-count, simulation, literature, visual, delivery, and scope-limit claims.
- The dashboard can inspect generated artifacts, open local modular Learn material, and, when SkillTree is available, hand off subject and quiz state to the official SkillTree runtime.
- SkillTree is cited and discussed as an NSA-origin open-source training platform, with explicit non-endorsement and deployment-boundary language.
- Project code/content metadata currently declares MIT, while third-party materials are
  either inventoried as vendored notices or cited/linked without relicensing.
- The owner-confirmed public target is
  `ActiveInferenceInstitute/Active_Skillference`, and that target now exists as an empty
  public repository; the claim becomes release-allowed only after the repository carries
  published content and a real release, and the release inventory is refreshed.
- Platform-facing source-repository links and release dates are not release-allowed while
  that target holds no published content.

## Claims To Avoid Until Future Evidence

- Do not claim that a live SkillTree service was verified unless Docker SkillTree is reachable and a real quiz route renders in Chrome.
- Do not claim empirical learner effectiveness, operator competence, or population-level educational impact.
- Do not claim national-security-grade security, NSA approval, government validation, deployment hardening, or secure production operation.
- Do not publish DOI, repository, or archival metadata that disagrees with the real
  deposit. Released at v1.0.0: the code is public at
  `https://github.com/ActiveInferenceInstitute/Active_Skillference` and archived at
  `https://doi.org/10.5281/zenodo.21865644`. Identifier fields are populated from that
  deposit and must stay byte-identical to `data/zenodo_reservation.json`; a value that
  does not match the record is a fabricated identifier and fails the gate.
- Do not assert a version-specific DOI, a second release tag, or an archive record that
  does not exist. `version_doi` and `version_record` stay blank until a versioned deposit
  is actually minted.
- Do not treat MIT signposting as counsel-approved IP clearance, trademark clearance, or
  production deployment authorization.

## Current Blockers

- DOI/Zenodo release is blocked until an actual release tag and deposit exist.
- Public repository release is blocked until the confirmed target
  `ActiveInferenceInstitute/Active_Skillference` holds published content and a real release
  tag, and repository metadata is refreshed. The target's existence cleared the
  reachability question only; the publication question is still open.
- Learner-outcome claims are blocked until a real study produces evidence.
- Live deployment claims are blocked until Docker SkillTree, dashboard handoff, privacy,
  security, trademark, and access-control reviews are complete.

## Minimal Initial-Publication Gate

Before an initial static public-review publication, run:

```bash
uv run pytest --cov=src --cov-fail-under=90
uvx ruff check src scripts tests && uvx ruff format --check src scripts tests
uv run mypy src
uv run python scripts/build_curriculum.py
uv run python scripts/analyze_scholarship.py
uv run python scripts/run_kernels.py
uv run python scripts/export_skilltree.py
uv run python scripts/validate_american_english.py
uv run python scripts/validate_claim_support.py
uv run python scripts/validate_manuscript_artifacts.py
uv run python scripts/validate_manuscript_variables.py
uv run python scripts/validate_live_counts.py
uv run python scripts/validate_roadmap.py
uv run python scripts/ensure_web_math.py
uv run python scripts/validate_web_math.py
uv run python scripts/validate_release_readiness_inventory.py
```

Also re-check the public-target blocker. An empty result means the repository exists but
nothing is published there, which keeps the blocker in force:

```bash
git ls-remote --heads https://github.com/ActiveInferenceInstitute/Active_Skillference.git HEAD
```

For a DOI-backed release or deployment publication rather than a static public-review
release, also complete the live SkillTree, publication-metadata, security/privacy,
trademark, and access-control roadmap tasks.
