# Output Inventory — Active Skillference

> Every file in `output/` is **disposable but regeneratable**. This document is the
> contract between the scripts and the manuscript: it inventories what is produced,
> which function/script emits it, and which step it lands in. This is a **local-only**
> project — there is no promoted monorepo `output/<project>/` copy; the artifacts below
> are authoritative directly under `Active_Skillference/output/`.

Paths in the table are relative to the project root (`Active_Skillference/`).

The numbered manuscript figures are produced together by `src/figures/plots/registry_io.py::render_all()`,
which `src.pipeline.generated_outputs.build_generated_outputs()` invokes with the
scholarship audit payload. The generated
cover and named-skill atlas are separate front-matter assets: they are validated and
exposed to the dashboard but are not listed in `figure_registry.json` or cross-referenced
as manuscript figures. The manuscript
render also emits per-section slide PDFs
and HTML under `output/slides/` and `output/web/` as renderer by-products; they are not
part of the curriculum/provenance contract and are not inventoried here.

The figure registry is also the dashboard's figure-semantics source. `src/figures/registry.py`
owns the typed loader and canonical contract fields; `src/figures/registry_manifest.py`
owns the generated row payload and semantic overrides. Each registered
visual carries the shared grammar note, chart family, subtitle/source context, takeaway,
data source, data grain, encoding, palette policy, palette roots, non-color encoding,
interpretation boundary, false-certification risk, accessibility note, mobile reading
note, QA role, and claim tokens. The figure producer keeps meaningful chart text at or
above the shared 9.5px-equivalent floor and reserves the smaller 8.5px text role for
source/caveat notes. The dashboard artifact gallery reads those fields for figure cards,
shows a larger full-size image preview link before long metadata, and groups metadata by
Question / Grain / Boundary / Failure before optional encoding and QA details; missing or
stale registry output degrades to a plain artifact link instead of changing artifact ids.
Dense figures can also carry `table_companion_id`; `output/data/figure_table_companions.json`
is the matching read-only table surface, and `validate_manuscript_artifacts.py` fails if a
referenced companion id is missing, empty, or bound to the wrong figure label.

The local learner dashboard adds one generated lesson-material contract:
`course_material_index.json` and `course_material_audit.json`. These files are derived
from the curriculum graph and `data/course_material_sources.yaml`; they contain
structured local lesson metadata and commit-pinned external pointers, not copied
upstream course prose. The dashboard serves static assets from `src/dashboard/assets/`
and reads the files above through `src/dashboard/artifacts.py`; missing outputs are
reported in the dashboard instead of being regenerated implicitly. Local SkillTree
bootstrap credentials live under ignored
`.active_skillference_local/`; that directory is runtime state, not a research artifact.
Shared JSON object/list reads and deterministic generated-artifact writes use
`src/artifacts/json_io.py`; script wrappers should not open-code artifact JSON schemas.

## How the artifacts relate (the provenance chain)

```
src/kernels/examples.py (build_claim_registry)
        │  registers named claims
        ▼
output/data/claims.json ──┐
        │                 │ same registry drives manuscript_variables.json
        ▼                 ▼
{{claim:NAME}} tokens in src/curriculum/catalog_data/  +  manuscript/*.md
        │  render (fail-closed) — every token must resolve, no bare numbers
        ▼
output/data/skilltree_project.json  (+ figures read the same registry/graph)

manuscript/*.md citations + references.bib + data/scholarship_sources.yaml
        │  validate_scholarship (fail-closed)
        ▼
output/data/scholarship_coverage.json + output/data/scholarship_source_health.json
        │                 │
        ▼                 ▼
output/figures/scholarship_coverage.png + output/figures/scholarship_source_health.png
        │
        ▼
output/data/scholarship_source_health_network.json

output/data/scholarship_coverage.json + data/manuscript_claim_support.yaml
        │  audit_scholarship_gaps (fail-closed frontier source contract)
        ▼
output/data/scholarship_gap_report.json

data/manuscript_claim_support.yaml + manuscript/*.md
        │  validate_claim_support (fail-closed)
        ▼
output/data/manuscript_claim_support.json + output/figures/scientific_evidence_matrix.png
output/figures/validation_intent_mismatch_matrix.png

output/figures/figure_registry.json + manuscript/*.md + src/dashboard/artifacts.py
        │  validate_manuscript_artifacts (fail-closed)
        ▼
output/data/manuscript_artifacts.json
        ▲
        │  dense figure companion ids must resolve
output/data/figure_table_companions.json

manuscript/config.yaml book.cover.image + output/figures/active_skillference_cover.png
        │  validate_cover_asset (fail-closed)
        ▼
output/data/cover_asset_audit.json

manuscript/config.yaml front_matter.page_two_visual.image + output/figures/active_skillference_skill_atlas.png
        │  validate_front_matter_visual (fail-closed)
        ▼
output/data/front_matter_visual_audit.json

src/curriculum/catalog_data/ + data/course_material_sources.yaml
        │  build_course_materials (fail-closed, claim tokens rendered)
        ▼
output/data/course_material_index.json + output/data/course_material_audit.json
```

Change a kernel and the claim, the rendered skill content, the manuscript variables, and
the figures are regenerated together. The artifact audit separately catches label,
cross-reference, PNG-content, caption/alt-text, semantic metadata, claim-token, or dashboard-inventory drift that shared numeric provenance cannot
catch by itself.

## Adding a new output file

1. Add the producing function in the right module — figures in `src/figures/plots/`
   (wired through `render_all()`); JSON via the relevant script.
2. Wire it into the appropriate script (`scripts/build_curriculum.py`,
   `scripts/run_kernels.py`, or `scripts/export_skilltree.py`).
3. Append a row to the table above naming the file, role, generator, and step.
4. If the manuscript consumes the value, reference it as `{{claim:NAME}}` (and register
   the claim in `src/kernels/examples.py`), then re-run the sequence.

## Regeneration sequence

Run from the project root:

```bash
uv run python scripts/build_curriculum.py    # curriculum stats and diagnostic gap map
uv run python scripts/analyze_scholarship.py # scholarship coverage, source-health network, figures
uv run python scripts/audit_scholarship_gaps.py  # output/data/scholarship_gap_report.json
uv run python scripts/run_kernels.py         # claims, scholarship, figures, artifact audit
uv run python scripts/build_course_materials.py  # re-check local Learn material records
uv run python scripts/validate_course_material_sources.py --online  # verify pinned external paths
uv run python scripts/validate_scholarship_sources.py  # re-check scholarship source health
uv run python scripts/validate_claim_support.py  # re-check scientific claim support
uv run python scripts/validate_manuscript_artifacts.py  # re-check generated figure surfaces
uv run python scripts/validate_manuscript_variables.py  # re-check live-count tokens
uv run python scripts/validate_live_counts.py  # re-check stale counts in docs/metadata
uv run python scripts/validate_roadmap.py      # re-check tasks.yaml, TODO.md, docs/todo/
uv run python scripts/validate_release_readiness_inventory.py  # re-check release inventory
uv run python scripts/export_skilltree.py    # output/data/skilltree_project.json (fail-closed)
uv run python scripts/validate_web_math.py   # re-check MathJax on dashboard and web render
uv run python scripts/serve_learner_dashboard.py --check  # read-only dashboard status
# optional live SkillTree bootstrap/seed:
uv run python scripts/bootstrap_local_skilltree.py --base-url http://localhost:8080
# optional manuscript render → output/pdf/Active_Skillference_combined.pdf (see rendering_pipeline.md)
```
